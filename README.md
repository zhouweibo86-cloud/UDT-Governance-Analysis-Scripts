# Reproducibility Materials

## Version 2 – Revised R Reproducibility Package

The reproducibility package corresponding to Version 2 of the manuscript is available in:

**[`DGRI_R/`](./DGRI_R/)**

The revised analysis uses:

- EU27, 2022–2024
- 81 country-year observations
- Digital Governance Readiness Index (DGRI)
- R-based raw-data-to-results workflow
- Country-clustered CR1 standard errors
- 9,999 null-imposed wild cluster bootstrap-t replications

The original Version 1 workflow is preserved under the **v1.0.0** tag.

For the revised workflow and reproduction instructions, see:

**[`DGRI_R/README.md`](./DGRI_R/README.md)**
